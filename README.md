# 🌙 Samay — Aesthetic AI Productivity App

> A calm, minimal, anime-inspired productivity app designed for students, developers, and deep workers.

---

## ✨ Overview

**Samay** is a beautifully designed productivity web app that focuses on:

- Minimalism 🧘
- Aesthetic experience 🎨
- Deep work & focus ⏳

Unlike traditional todo apps, Samay blends **AI + design + emotion** to create a workspace you actually _want_ to open.

---

## 🎯 Target Users

- Students 👨‍🎓
- Developers 👨‍💻
- Freelancers 🧑‍💼
- Anyone who spends long hours on a laptop

---

## 🌟 Features

### 📝 Core Features

- Create, edit, delete tasks
- Task prioritization
- Clean & distraction-free UI
- Daily planning system

### 🎨 UI/UX

- Calm anime-inspired design
- Smooth animations (GSAP)
- Minimal color palette
- Focus-first layout

### 🤖 AI Features (Planned / In Progress)

- AI-generated task suggestions
- Smart scheduling
- Mood-based productivity recommendations
- Natural language task input

### 🔮 Future Features

- Pomodoro timer
- Ambient sounds (lofi, rain, etc.)
- Habit tracking
- Weekly analytics dashboard
- Cross-device sync

---

## 🛠️ Tech Stack

### Frontend

- Next.js (App Router)
- React
- Tailwind CSS
- GSAP (animations)

### Backend

- Next.js API routes
- OpenAI API (for AI features)

### Database (Planned)

- MongoDB / PostgreSQL

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/your-username/samay.git  
cd samay

### 2️⃣ Install dependencies

npm install

### 3️⃣ Run development server

npm run dev

App will run on:  
http://localhost:3000

---

## 🔑 Environment Variables

Create a `.env.local` file:

OPENAI_API_KEY=your_api_key_here
